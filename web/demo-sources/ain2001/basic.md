# AIMA5001: Basic

**AIMA 5001** (graduate): LMS-first path for the *AIMA* spine—emphasis on **AI problem solving** (search, planning, learning, agents). This demo page is built from Markdown at `web/demo-sources/ain2001/basic.md` and published under `/demos/course/ain2001/basic/` when you run `npm run build:demos`.

## What institutions license

- Thin **IMS Common Cartridge** for Canvas, Moodle, or similar LMS imports
- **PDF** slide samples aligned to the *Artificial Intelligence: A Modern Approach* spine
- Written **assignments** suitable for committee and syllabus review without GitHub on day one

```{note}
Basic is the lowest-friction path for curriculum committees that live in the LMS first; the same chapter spine can graduate students to GitHub-native variants later.
```
