The core idea

The agent–environment loop

  • Perceive — the agent reads the environment through sensors.
  • Decide — a policy maps what it perceives to an action. The design question is what makes that mapping rational.
  • Act — actuators change the environment, and the loop repeats.

A rational agent, in miniature

Policy as a function

# choose the action with the best expected outcome
def agent(percept, model):
    actions = model.actions(percept)
    return max(actions, key=model.expected_value)
Run it, change expected_value, and explain how behavior shifts — the pattern for every assignment.
